# Учебные критерии версии 1

Эти два правила заданы для демонстрации. Они не являются корпоративным стандартом. Для применения в команде владелец процесса должен проверить их соответствие своей работе.

## R1. Понятный результат

Из текста понятно, какое изменение или результат требуется получить. «Экспортировать отфильтрованные заявки в CSV» достаточно. «Улучшить сервис» без уточнения результата недостаточно. Не требуй отдельного раздела «Цель», метрик бизнеса или конкретной структуры документа.

## R2. Проверяемая приёмка

Есть хотя бы одно конкретное условие, по которому можно наблюдать выполнение задачи: поведение при заданных условиях, пример входа и ожидаемого выхода, измеримый порог или однозначно проверяемое свойство результата. Одного названия функции («добавить экспорт») недостаточно. «Стало удобно», «работает правильно» и «проверить вручную» без указания ожидаемого результата также недостаточны.

Не требуй исчерпывающей спецификации и не оценивай полноту всех возможных сценариев. Условие может находиться в любом месте текста, а не только под заголовком «Приёмка».
