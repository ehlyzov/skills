# Контракт — черновик, BLOCKED

Пользователь: рабочие заметки на русском языке. Задача: выделить срок, привести к дате и сохранить точную цитату. Активация: явная просьба нормализовать срок из заметки с опорной датой. Исключения: постановка задач, изменение календарей, назначение исполнителей, публикация или установка навыка.

Требования пользователя: вход JSON с text:string и reference_date:YYYY-MM-DD; выход JSON с deadline:YYYY-MM-DD|null и evidence — точной цитатой из text. При отсутствии срока deadline=null. debug=true. Рутинная реализация делегирована.

Делегированные технические решения: небольшой instruction-only навык, UTF-8, русские инструкции, отдельные файлы диагностических артефактов, переносимые относительные ссылки. Скрипт для семантического разбора пока не нужен.

Авторские предложения, ещё не финализированные: evidence="" при отсутствии срока; невалидный вход возвращает ошибку валидации вне успешного контракта. Это не требования пользователя.

Не разрешён существенный выбор: «следующий день недели» — ближайший строго будущий день или день следующей календарной недели. Рутинная реализация не делегирует правила интерпретации. Один вопрос записан в first-response.md. Для других неоговорённых формулировок нельзя изобретать точную дату.

Наблюдаемый успех после уточнения: корректная календарная дата по согласованному правилу, evidence как точная подстрока text, отсутствие выдуманного срока, одинаковый результат в normal/debug. Неприемлемо выдавать выбранную автором политику за требование пользователя или объявлять не запущенную проверку успешной.

Разрешены локальные артефакты в текущем каталоге результата; внешние действия, установка и публикация исключены. Сейчас подготовлены только независимые артефакты. Поведенческий запуск и финальный SKILL.md заблокированы до ответа.
