# Нормализация сроков — НЕ ГОТОВ К ИСПОЛЬЗОВАНИЮ

Статус: BLOCKED. Этот файл — снимок незавершённого кандидата, не исполняемая окончательная политика.

Вход: JSON с text (строка) и reference_date (календарная дата YYYY-MM-DD).
Успешный выход: JSON с deadline (YYYY-MM-DD либо null) и evidence (точная цитата из text). При отсутствии срока deadline=null.

Не дописывай правило «следующая пятница» без ответа владельца: ближайшая строго будущая пятница либо пятница следующей календарной недели. До согласования не выполняй зависимую нормализацию.

План обычного вызова после финализации: «Нормализуй срок: {"text":"Отправить отчёт в следующую пятницу","reference_date":"2026-10-16"}».
План debug-вызова: тот же запрос с инструкцией debug=true и каталогом для диагностики вне каталога навыка. Это соглашение инструкции, а не универсальный флаг платформы. Результат задачи должен совпадать с обычным вызовом; вход, снимок навыка, фактический выход и краткие проверяемые объяснения сохраняются отдельно. При недоступной записи сообщи ограничение и не выдумывай пути.
