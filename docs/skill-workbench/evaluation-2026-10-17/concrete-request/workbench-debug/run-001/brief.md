# Краткий контракт

Пользователь: авторы и читатели расшифровок встреч. Задача — извлечь явные поручения в JSON без внешних действий.

Поставленные требования: `request.json`. Все данные этой проверки синтетические. Активация — извлечение поручений из расшифровки; исключения — оценка людей, рассылка и создание задач.

Наблюдаемый успех: корректный статус, только явные действия, точные цитаты, отсутствие выдуманных владельцев/сроков, одинаковые решения в normal/debug. Неприемлемы потеря явного поручения, превращение предположения в поручение, догадка о владельце, неточная evidence, внешние действия.

Делегированные технические решения: пробельная строка считается пустой; debug задаётся текстом вызова вне входного JSON. `reference_date` задаёт локальную календарную дату; «завтра» +1 день, «через N дней» +N, ближайший названный день недели — не раньше reference_date. Срок с неоднозначной датой сохраняется словами. Отрицания, цитируемые прошлые обещания и гипотезы сами по себе не создают текущего поручения.

Последствия этих решений ограничены извлечением текста; нерешённых consequential требований нет. Навык создаётся в папке результата без установки. Автор сам исполняет случаи в текущем контексте; независимая проверка не заявляется. Проверка автоматического выбора навыка недоступна и будет NOT_RUN; forced invocation не доказывает routing.
